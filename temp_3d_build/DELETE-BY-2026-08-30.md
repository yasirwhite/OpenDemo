# Delete this folder by 2026-08-30

`temp_3d_build/` is the working directory from the Kite reference-matching effort. It is
kept on the `feature/3d-renders` branch **temporarily**, and should be removed — along
with this branch — by **30 August 2026**.

## Why it can go

Everything durable was moved into the repo proper. Nothing here is an input to anything:

| what is in here | where it lives now |
|---|---|
| the six tuned shots (`cuts13.js`, `scene3.html`) | `src/lib/cinematic3d/presets/*.js` |
| what each shot looks like | `src/lib/cinematic3d/presets/previews/` |
| `MISTAKES.md` | `docs/reference-matching.md` |
| `ZOOM-MAP.md`, `SCORING.md`, `CHECKLIST-v2.md` | the measurements that mattered are in that doc's per-reference notes |
| the kite reference film | `references/references.json` — re-fetchable, md5 verified |
| `clips/` reference twins | re-cut from the source with `tools/cut-sheets.mjs` |
| `kite-match-FINAL.mp4`, `deliverables/` | outputs. Regenerate from a config. |

## Why deleting it matters

`frames2/` alone is **250 MB of tracked JPEGs**, plus ~40 MB of MP4s. All of it was added
on this branch — `main` carries none of it.

Removing the files from the working tree does **not** shrink a clone; the objects are
already in history. To actually reclaim it, squash the branch into a single commit off
`main` with these paths excluded, then `git gc --prune=now`. Deleting the branch after
merge does the same thing.

## Before deleting

Confirm the presets still render:

```bash
node src/lib/cinematic3d/render.mjs src/lib/cinematic3d/configs/examples/login-demo.config.json 3
```

If that produces a clean MP4, nothing in this folder is needed.
