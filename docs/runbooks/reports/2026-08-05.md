## Runbook friction (fix before unattended runs)

1. Parallel agents race on the shared `dist/bundle.js` — private-stage builds with config markers are now the proven discipline; make it standard in the runbook.
2. 8fps reference-frame dumps carry timing drift — full-decode extraction only.
3. A `cd` compound command is denied by the permission layer and silently killed an agent turn; a denied call stranded one assembler ~4h. Never use `cd`; adapt on denials.
4. Cancelled runs' subagents kept working ~25 min after stop; a killed workflow can die silently with no notification — verify by transcript mtimes, not assumptions.
5. Workflow `args` never reached scripts (scratch paths say `nightly/undefined/`); workflow resume-from-cache invalidated twice — direct agent relaunches proved more reliable than resumes.
6. Vetting needs the human's eye on chosen references before cloning (produced-layer test), and every deliverable needs the side-by-side watched before landing — both now encoded in the runbook.
